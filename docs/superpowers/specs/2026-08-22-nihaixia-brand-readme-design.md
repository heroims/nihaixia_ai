# 倪海厦离线问答：README 与品牌资源设计规格

## 背景与目标

本项目是一个离线优先的 Flutter 中医问答 App，核心能力包括 SQLite 知识库检索、端侧 LLM RAG 合成、结构化问法路由、云端拍照/Live 增强以及 Android/iOS 原生集成。当前根 README 已有较多技术事实，但产品叙事、AI 工程亮点、运行路径和面试展示价值没有形成完整入口；平台启动资源仍接近 Flutter 默认占位。

本次工作目标：

1. 重写根 README，使普通用户能快速理解产品，开发者能按文档运行和验证项目，并能清晰看到 AI 技术取舍与面试可讲亮点。
2. 为 App 建立“经方印章”视觉识别：朱砂红、宣纸米色、印章式“经方”标记。
3. 以同一套矢量源生成 Android/iOS 图标规格，并替换 Android 启动背景与 iOS LaunchScreen 资源。
4. 保持现有业务逻辑不变；资源接入应可在无模型文件时正常启动，并不新增网络依赖。

## 设计决策

### README 信息架构

根 README 采用双层叙事：

- **产品层**：一句话定位、适用场景、主要功能、离线/联网边界、免责声明。
- **工程层**：AI 能力亮点、架构分层、问答数据流、模型降级策略、知识库构建、测试矩阵、已知限制、目录结构与贡献入口。
- **面试层**：列出可演示的技术切入点和建议演示顺序，但不虚构性能指标或医疗效果。

命令示例使用仓库当前目录结构；模型、知识库等大文件继续明确标注为可选/不入库。README 与 `app/README.md` 的关系要清楚：根 README 负责项目总览，`app/README.md` 改为 Flutter 子项目的运行与平台调试补充，而不再保留模板占位文案。

### 品牌视觉

- 主色：朱砂红 `#9E3D32`
- 纸张色：宣纸米色 `#F3EAD8`
- 墨色：深棕 `#3F2B25`
- 辅助金：旧金 `#C9A67E`
- 图标核心：圆角方形底 + 内嵌双线印章框 + “经方”二字，外层留足安全区，避免小尺寸裁切。
- 启动页：宣纸米色全屏背景，中心朱砂红印章，辅以“倪海厦 · 离线中医问答”小字；不放复杂插画、动态元素或医疗功效宣称。

### 资源生成与接入

采用纯矢量、程序化生成：

1. 在 `app/assets/branding/` 保存可审阅的 SVG 源文件和生成说明。
2. 使用本地脚本将 SVG 栅格化为 Android `mipmap-*` 密度图与 iOS `AppIcon.appiconset` 所需尺寸。
3. Android 继续使用 `@mipmap/ic_launcher`，更新 `launch_background.xml`，确保启动窗口不再是纯白。
4. iOS 更新 `AppIcon.appiconset` 的 Contents.json 对应图片，并更新 `LaunchImage.imageset` 与 `LaunchScreen.storyboard` 的背景/中心布局。
5. 必须保留 iOS 深色模式/不同屏幕尺寸的安全边距；启动页只依赖静态资源。

## 组件与边界

- **品牌源文件**：只负责图形和色彩，不依赖 Flutter 运行时。
- **平台资源**：只负责各平台命名、尺寸和启动窗口引用。
- **README 文档**：只描述已实现能力与可验证命令，不把视觉资源或面试建议写成业务承诺。
- **现有 Flutter UI**：本次不重构主题系统；若需要让运行中首页与启动页协调，只补充最小化的色彩常量或图标引用，不改变交互。

## 验证标准

### 文档

- 新开发者能从 README 找到 Flutter、Python、知识库和可选模型的运行路径。
- 能在 README 中定位端侧 RAG、纯检索降级、结构化查询、云端增强和测试入口。
- 所有命令、路径和当前代码一致；不承诺未经测试的准确率、速度或医疗效果。

### 资源

- Android 图标覆盖 mdpi/hdpi/xhdpi/xxhdpi/xxxhdpi，尺寸和文件格式正确。
- iOS AppIcon 的 Contents.json 引用完整且所有文件存在；1024px 图标可被 Xcode 接受。
- Android 与 iOS 启动页均显示米色背景和朱砂印章，启动窗口无拉伸、裁切或纯白闪屏。
- `flutter analyze`、相关 Flutter widget/resource 测试和至少一次 Android/iOS 资源构建或静态校验通过。

## 非目标

- 不重写问答算法、模型推理参数或数据库 schema。
- 不引入第三方图标生成包或在线资源服务。
- 不生成或提交 `.gguf` 模型文件。
- 不对中医内容做医学有效性背书。
