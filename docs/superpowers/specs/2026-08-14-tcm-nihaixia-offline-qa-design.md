# 倪海厦中医离线问答 App — 设计文档

日期：2026-08-14
状态：已确认

## 1. 背景与目标

用 Flutter 实现一款离线优先的倪海厦中医问答 App，以 [nihaixia 知识库](https://github.com/jangviktor-web/nihaixia)（~4MB / 3.5M 字 Markdown 蒸馏内容）为知识库，面向普通大众，主打「输入症状 → 辨证建议」。核心价值是**可溯源、离线可用、分层可用**。

### 知识库构成（已验证）

| 内容 | 规模 | 来源文件 |
|---|---|---|
| 伤寒论条文 | 129 条 | `modules/01_shanghan_sun.md`, `02_shanghan_other.md` |
| 金匮 | 23 篇 | `modules/04_jingui.md` |
| 黄帝内经 | 71 篇 | `modules/05,08` |
| 神农本草 | 345 种 | `modules/09_zhenjiu_bencao.md` |
| 医案 | 849 例（含分类 245 例） | `modules/03_yian.md`, `cases/*`, `distilled_cases.md` |
| 针灸 | 穴位/经络/五输穴 | `modules/09`, `references/distilled/02,04` |
| 诊断公式 | 8 公式 + 七步走 | `references/distilled/01-six-meridian-formulas.md` |

## 2. 核心需求（已与用户确认）

1. **交互**：自由问答 + 引导式诊断 双 Tab。
2. **架构**：纯检索兜底 + 打包端侧小模型（≤1.7B）+ 可选云端增强。
3. **设备**：广覆盖，含 4GB RAM 老机型（需自动降级）。
4. **拍照/Live**：仅开启云端配置后启用，默认关闭。
5. **目标平台**：国内 Android 为主，个人/自用、侧载分发，不上架商店。
6. **合规**：常驻免责声明 + 急危重症警示，不采集健康数据。

## 3. 整体架构

│  │  (Tab 1)  │ │  (Tab 2)  │ │ (云端配置/拍照)  │  │
│  └─────┬─────┘ └─────┬─────┘ └───────┬────────┘  │
│        │             │                │          │

│  ┌─────▼─────┐  ┌─────▼─────┐  ┌─────▼─────┐    │
│  │ 规则引擎    │  │  BM25检索  │  │ 端侧LLM    │    │

│        ┌─────────────────────────────┘          │

**核心原则**：分层可用——老机型只有「检索 + 规则引擎」；中端机加「端侧 LLM RAG」；有云端配置才开放「拍照/Live」。每层独立可测。

## 4. 知识库离线构建与数据模型

**构建期工具**（开发机运行，Python，产物打进 App assets）：

| 输入（repo） | SQLite 表 | 说明 |
|---|---|---|
| `references/distilled/01-six-meridian-formulas.md` | `formulas` | 8 公式 → 结构化 IF-THEN 规则 |
| `modules/01,02` 伤寒论 | `tiao_wen` | 129 条，含条文号/原文/解读/方 |
| `modules/04` 金匮 | `tiao_wen` + `formulas` | 23 篇 |
| `modules/09` 神农本草 | `herbs` | 名称/性味/归经/主治/用量/禁忌 |
| `modules/03`, `cases/*`, `distilled_cases.md` | `cases` | 849 例，病名/症状/处方/类型标签 |
| `modules/09` 针灸 | `acupoints` | 穴名/经络/位置/主治 |
| `SKILL.md` + 其余 modules | `raw_chunks` | 逐段 chunk，BM25 兜底 |

**关键决策**：
- 诊断公式走**结构化规则**而非 LLM（稳定、快、可溯源）。
- 结构化表解决 80% 精确查询，BM25 段落检索解决开放问题。
- 中药/方剂名维护**同义词表**（如 小柴胡汤=柴胡汤、生/炮附子），手工小词表。
- 版权：repo 为 MulanPSL-2.0，可打包，App「关于」页署名。

## 5. 检索、RAG 合成与端侧 LLM

**BM25 检索层**（本地无网络）：
- SQLite FTS5。中文分词：构建期 jieba 预切分存 token 列，检索期直接查（推荐；备选 `simple` tokenizer + unigram）。
- 流程：意图路由 → 按意图选表（精确字段匹配优先）→ 失败则 FTS5 BM25 → top-k 段落。

**端侧 LLM 层**：
- 引擎：`llama_cpp_dart`（Flutter 绑定，活跃维护）。
- 模型：Qwen 3 1.7B Q4_K_M（~1.1GB），打进 App 首次启动解压。
- 用途：**仅做 RAG 合成**——检索证据段落 → 拼 prompt → 组织成「倪师风格」回答并附出处。不做自由生成。

**Prompt 模板**（防幻觉关键）：
```
你是倪海厦经方中医助手。请仅基于以下资料回答：
【资料】...
【问题】...
要求：1) 严格基于资料，不编造 2) 注明出处 3) 资料不足时明确说"资料中未找到"
```

**降级策略**（运行时自适应）：
- 内存 < 5GB → 不加载 LLM，纯检索。
- 模型加载失败 / 被系统杀 → 自动回退检索层。
- 每次回答显示「来源段落」，可点开看原文。

## 6. 引导式诊断 Tab（规则驱动）

基于「倪师六健康标准 + 八问」分步问卷：
1. 基础信息（性别/年龄/作息）
2. 寒热 → 3. 汗出 → 4. 口渴（含饮冷/饮热）
5. 二便 → 6. 睡眠 → 7. 饮食 → 8. 舌象/脉象（自选描述）

走 `formulas` 表的 IF-THEN 决策树（如「无汗+恶寒+体痛 → 太阳伤寒/麻黄汤方向」）。输出：辨证结论 + 代表方剂方向 + 来源条文链接 + 「仅供参考，请咨询医师」提示。问卷可跳步，答案越全辨证越细。

## 7. 云端增强层（默认关闭）

- 设置页手动填 API key 解锁：**拍照看舌象**（视觉模型描述舌质/舌苔 → 结果接入引导诊断）和 **Live 对话**（流式实时追问）。
- 云端仅做「辅助输入」，最终辨证仍走本地规则引擎，不直接下结论。
- API 兼容 OpenAI 格式，支持任意兼容 endpoint。

## 8. 安全与合规

- 结果页常驻免责声明：「本 App 为倪海厦中医教学知识整理，仅供学习参考，不构成医疗建议，请咨询执业医师」。
- 急危重症关键词触发警示卡（胸痛/呼吸困难/呕血/昏迷等 → 立即就医）。
- 不采集任何用户健康数据，纯本地存储；无账号/无上传。

## 9. 技术栈

- Flutter + `llama_cpp_dart` + `sqflite`/`drift`
- 构建期 Python 工具（解析 markdown → SQLite + FTS5 索引）
- 端侧模型：Qwen 3 1.7B Q4_K_M（~1.1GB）
- 目标：Android（API 26+）优先，iOS 兼容

## 10. 非目标（YAGNI）

- 不做账号、登录、云同步、付费。
- 不做多知识库（李可/胡希恕等后续再说）。
- 不做端侧多模态（视觉模型端侧目前不可行）。
