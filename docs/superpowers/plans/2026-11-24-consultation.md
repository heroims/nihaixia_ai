# 多轮问诊实施计划

目标：已批准的症状追问 → 动态检索 → 用户核对 → 有据参考结果流程；知识问题直接回答。

- [x] 新增问诊服务测试：历史、检索循环、确认门槛、失败保持状态、动态云端。
- [x] RagSynthesizer 提供受限的指令生成接口，共用云端/本地降级，修复动态配置 enabled。
- [x] ConsultationSession 管理对话和阶段；模型返回 search/ask/confirm/final/knowledge JSON；每轮最多四次模型动作，来源由实际检索维护。
- [x] QaTab 展示完整消息、阶段、确认和新对话按钮；失败保留历史。
- [x] 运行新增测试、现有回归及静态检查，更新 README。

约束：只有用户点击确认才能结束问诊；缺少证据禁止形成结果；无模型保持知识查询路径；模型输出格式错误明确提示重试。不会生成处方剂量或声称确诊。

验证记录：全套测试 155 项通过、真实 GGUF 测试 1 项跳过；新增界面测试通过。Dart 针对改动文件静态检查通过；Flutter analyze 的 LSP 在中文路径发生协议解析异常。没有调用真实云端服务。
